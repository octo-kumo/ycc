## Key Design Decisions Recorded

1. **A sweep finds defects by AREA; a threshold is only findable if something names it.** → `audit_thresholds.py` + pinned boundary blocks in `gen_ulp_table.py`.

2. **Independent and correlated pair draws are OPPOSITE, not two settings of one knob.** Independent makes wide ratios common and `s == m` rare. `audit_pairs.py` now carries both families.

3. **Dead branches are RECORDED, not deleted.** `tan`'s two infinity arms (`sc[1]==0.0` and `cs==0.0`) never fire — but they are the GUARD. If a future reduction change lets a zero through, the guard keeps the answer infinity; without it the division is 0/0 → NaN. Deleting an unfireable branch is how the day it fires arrives unguarded.

4. **Y's NaN has sign bit SET (0xFFF8… vs C's 0x7FF8…).** IEEE leaves generated quiet NaN sign unspecified. Both runtimes print `nan` (no sign). `1.0/nan` is NaN, not ±inf. Recorded in `t332_bulk_empty.y` because a comment claimed otherwise and the fixture's own output contradicted it — **third time this work a comment I wrote was wrong, caught by reading output**.

5. **A printed number nothing increments, or a line labelled with a value it does not hold, is a gate that checks nothing.** Happened twice writing fixtures (`t331`'s `0.0 - 0.0` labelled `-0.0`; `t320`'s `infs` never incremented).
