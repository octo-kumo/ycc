# AST node shapes

> Generated by `src/tools/compiler_docs.y` from `src/y/ast_schema.y`.
> Do not edit this file by hand; run `make compiler-docs`.

`Node` is a generated union of exact records. Every node carries `k` (a `tags.y` tag such as `K.bin`), `line` and `col`; the table below lists the fields that make each shape.

The union and its helper walks are generated by `ast_nodes.y` through `shape_codegen.y`; the schema is the source of truth. A node's `k` selects its shape, and code casts only after checking `k`.

## Shapes

### `Leaf`

A literal or identifier leaf. `k` says which (number, string, byte, big integer, boolean, identifier).

| field | type | meaning |
|---|---|---|
| `v` | `str` | Value text; how to read it depends on `k`. |

### `Bare`

The void value: an empty `else` arm, an omitted loop clause, or `()`.

_No shape-specific fields._

### `Wrap`

One child expression. `k` distinguishes address-of (`K.addr`), dereference (`K.deref`) and `return` (`K.ret`).

| field | type | meaning |
|---|---|---|
| `e` | `Node` | The operand expression. |

### `Un`

Prefix unary operator: `-`, `!` or `~`.

| field | type | meaning |
|---|---|---|
| `op` | `str` | Operator spelling as written in the source. |
| `e` | `Node` | The operand expression. |

### `Bin`

Binary operator expression; `op` keeps the source spelling and the checker decides its meaning.

| field | type | meaning |
|---|---|---|
| `op` | `str` | Operator spelling as written in the source. |
| `l` | `Node` | Left operand. |
| `r` | `Node` | Right operand. |

### `ArrLit`

Array literal `[a, b, ...]`.

| field | type | meaning |
|---|---|---|
| `elems` | `[Node]` | Array elements, in source order. |

### `ArrRep`

Fixed-array repeat literal `[v; n]`.

| field | type | meaning |
|---|---|---|
| `v` | `Node` | Value text; how to read it depends on `k`. |
| `n` | `long` | Repeat count or fixed length. |

### `Assign`

Assignment to a simple binding. The renamer replaces `name` with the binding's unique name.

| field | type | meaning |
|---|---|---|
| `name` | `str` | Source name; rename.y makes it unique after parsing. |
| `v` | `Node` | Value text; how to read it depends on `k`. |

### `Block`

A statement sequence. Its value is the last statement without a semicolon.

| field | type | meaning |
|---|---|---|
| `stmts` | `[Node]` | Statements in the block. |

### `Call`

Call expression, including the desugared forms of `join`, `lock`, `spawn { ... }` and postfix `!`.

| field | type | meaning |
|---|---|---|
| `callee` | `Node` | The called expression. |
| `args` | `[Node]` | Call arguments, in source order. |

### `Decl`

A top-level or block-level `let`, `const`, `def` or `native` declaration. `typ` is the written annotation, or `K.tnone`.

| field | type | meaning |
|---|---|---|
| `kind` | `str` | Declaration kind: `"let"`, `"const"`, `"def"` or `"native"`. |
| `name` | `str` | Source name; rename.y makes it unique after parsing. |
| `typ` | `Type` | A type node; `K.tnone` means no annotation was written. |
| `v` | `Node` | Value text; how to read it depends on `k`. |
| `nline` | `long` | Line of the declared or referenced name. |
| `ncol` | `long` | Column of the declared or referenced name. |

### `Dot`

Field or property read `obj.key`; `nline`/`ncol` locate the name.

| field | type | meaning |
|---|---|---|
| `obj` | `Node` | The record, map or module expression on the left of a dot. |
| `key` | `str` | Field or entry name. |
| `nline` | `long` | Line of the declared or referenced name. |
| `ncol` | `long` | Column of the declared or referenced name. |

### `DotAssign`

Assignment to a record field `obj.key = v`.

| field | type | meaning |
|---|---|---|
| `obj` | `Node` | The record, map or module expression on the left of a dot. |
| `key` | `str` | Field or entry name. |
| `v` | `Node` | Value text; how to read it depends on `k`. |
| `nline` | `long` | Line of the declared or referenced name. |
| `ncol` | `long` | Column of the declared or referenced name. |

### `Err`

A parse or resolution error carried as a node so the compiler can report several diagnostics.

| field | type | meaning |
|---|---|---|
| `msg` | `str` | Human-readable diagnostic. |

### `For`

C-style `for (init; cond; step) body`; an omitted clause is `Bare`.

| field | type | meaning |
|---|---|---|
| `init` | `Node` | Loop initialization clause, or `Bare`. |
| `cond` | `Node` | Loop or branch condition. |
| `step` | `Node` | Loop step clause, or `Bare`. |
| `body` | `Node` | The loop or function body. |

### `Foreach`

`foreach (name in iter) body`.

| field | type | meaning |
|---|---|---|
| `name` | `str` | Source name; rename.y makes it unique after parsing. |
| `iter` | `Node` | The value a `foreach` walks. |
| `body` | `Node` | The loop or function body. |

### `ForRange`

`for name in lo..hi body`.

| field | type | meaning |
|---|---|---|
| `name` | `str` | Source name; rename.y makes it unique after parsing. |
| `lo` | `Node` | Range or slice lower bound, or `Bare`. |
| `hi` | `Node` | Range or slice upper bound, or `Bare`. |
| `body` | `Node` | The loop or function body. |

### `Func`

A function declaration or anonymous function literal. `defs` holds one default-value node per parameter.

| field | type | meaning |
|---|---|---|
| `params` | `[str]` | Parameter names, parallel to `ptypes`. |
| `ptypes` | `[Type]` | Parameter types, parallel to `params`. |
| `ret` | `Type` | Return type, or `K.tnone` when the parser leaves it to inference. |
| `body` | `Node` | The loop or function body. |
| `defs` | `[Node]` | One parameter-default node per parameter: a literal value, `Bare` for none, or `K.optarg` for an optional parameter. |
| `label` | `str` | Assembly label for a `native` declaration; empty for ordinary defs. |
| `ppos` | `[long]` | Packed source positions of the parameter names: `line * 65536 + col`. |
| `arrow` | `bool` | True for a `=>` function literal; false for a `def` or block function. |

### `IdxAssign`

Assignment to an index: `arr[idx] = v`.

| field | type | meaning |
|---|---|---|
| `arr` | `Node` | The array, slice or string being indexed. |
| `idx` | `Node` | Subscript expression. |
| `v` | `Node` | Value text; how to read it depends on `k`. |

### `If`

`if` with an optional else arm; `has_else` distinguishes an absent else from an empty one.

| field | type | meaning |
|---|---|---|
| `cond` | `Node` | Loop or branch condition. |
| `then` | `Node` | The `if` arm. |
| `els` | `Node` | The else arm; meaningful only when `has_else` is true. |
| `has_else` | `bool` | Whether an else arm was written (an empty else is distinct from none). |

### `IncDec`

Prefix or postfix `++`/`--`; `pre` says which form.

| field | type | meaning |
|---|---|---|
| `op` | `str` | Operator spelling as written in the source. |
| `pre` | `bool` | True for prefix `++x`/`--x`, false for postfix. |
| `tgt` | `Node` | Assignment target. |

### `Index`

Subscript expression `arr[idx]`.

| field | type | meaning |
|---|---|---|
| `arr` | `Node` | The array, slice or string being indexed. |
| `idx` | `Node` | Subscript expression. |

### `RecLit`

Record literal (`K.rec`) or map literal (`K.map`), sharing one field layout.

| field | type | meaning |
|---|---|---|
| `keys` | `[str]` | Record field or map entry names, parallel to `vals`. |
| `vals` | `[Node]` | Record field or map entry values, parallel to `keys`. |

### `MatchEnd`

The end of a generated match chain: the subject, the types already covered, and the value-arm count.

| field | type | meaning |
|---|---|---|
| `e` | `Node` | The operand expression. |
| `cover` | `[Type]` | Types already covered by earlier match arms. |
| `vals` | `long` | Record field or map entry values, parallel to `keys`. |

### `Narrow`

A type test or cast; `k` is `K.rectest` for a union test and `K.narrow` for a narrowing cast.

| field | type | meaning |
|---|---|---|
| `e` | `Node` | The operand expression. |
| `typ` | `Type` | A type node; `K.tnone` means no annotation was written. |

### `OpAssign`

Compound assignment `target op= value`.

| field | type | meaning |
|---|---|---|
| `op` | `str` | Operator spelling as written in the source. |
| `tgt` | `Node` | Assignment target. |
| `v` | `Node` | Value text; how to read it depends on `k`. |

### `Slice`

Slice expression `arr[lo:hi]`; an omitted endpoint is `Bare`.

| field | type | meaning |
|---|---|---|
| `arr` | `Node` | The array, slice or string being indexed. |
| `lo` | `Node` | Range or slice lower bound, or `Bare`. |
| `hi` | `Node` | Range or slice upper bound, or `Bare`. |

### `SliceAssign`

Slice assignment `arr[lo:hi] = v`.

| field | type | meaning |
|---|---|---|
| `arr` | `Node` | The array, slice or string being indexed. |
| `lo` | `Node` | Range or slice lower bound, or `Bare`. |
| `hi` | `Node` | Range or slice upper bound, or `Bare`. |
| `v` | `Node` | Value text; how to read it depends on `k`. |

### `Store`

Store through a pointer: `*p = v` (after desugaring).

| field | type | meaning |
|---|---|---|
| `p` | `Node` | Pointer expression being stored through. |
| `v` | `Node` | Value text; how to read it depends on `k`. |

### `TypeDef`

Alias or record-union declaration. The renamer resolves aliases and usually removes these nodes.

| field | type | meaning |
|---|---|---|
| `name` | `str` | Source name; rename.y makes it unique after parsing. |
| `typ` | `Type` | A type node; `K.tnone` means no annotation was written. |

### `While`

`while (cond) body`.

| field | type | meaning |
|---|---|---|
| `cond` | `Node` | Loop or branch condition. |
| `body` | `Node` | The loop or function body. |
