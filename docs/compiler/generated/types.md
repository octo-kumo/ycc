# Type shapes

> Generated by `src/tools/compiler_docs.y` from `src/y/type_schema.y`.
> Do not edit this file by hand; run `make compiler-docs`.

`Type` is generated from the same schema as `Node`; `type_nodes.y` expands `TYPE_SHAPES` through `shape_codegen.y`. Every type carries `k`, and the table lists the fields each shape adds.

Three helper records are part of the schema's vocabulary:

- `Field { name: str, opt: bool, typ: Type }` — one record or packed field.
- `RetNote { typ: Type, line: long, col: long }` — a return site noted during inference.
- `TRef` is the one shape that may form a cycle; `unfold`/`teq` decide when to follow it.

## Shapes

### `TPrim`

A primitive type. Primitive kinds have no fields and are distinguished by `k` (`K.tlong`, `K.tbyte`, `K.tfloat`, `K.tbool`, `K.tstr`, `K.tvoid`, `K.tbigint`, `K.tnone`, `K.tunk`).

_No shape-specific fields._

### `TOf`

A one-child container. `k` says whether it is an array (`K.tarr`), an option (`K.topt`) or another unary type.

| field | type | meaning |
|---|---|---|
| `of` | `Type` | The element, option payload, pointee or unary child type. |

### `TFix`

A fixed array `[T; n]`.

| field | type | meaning |
|---|---|---|
| `n` | `long` | Fixed array length. |
| `of` | `Type` | The element, option payload, pointee or unary child type. |

### `TMap`

A map `{key => value}`.

| field | type | meaning |
|---|---|---|
| `key` | `Type` | Map key type. |
| `of` | `Type` | The element, option payload, pointee or unary child type. |

### `TRec`

A structural record. Fields are exact and ordered by the schema; tuple fields are named `$0`, `$1`, ...

| field | type | meaning |
|---|---|---|
| `fields` | `[Field]` | Record or packed fields, in layout order. |

### `TFunc`

A function type: argument types and return type.

| field | type | meaning |
|---|---|---|
| `args` | `[Type]` | Function argument types. |
| `ret` | `Type` | Function return type. |

### `TName`

A named alias before rename.y expands it.

| field | type | meaning |
|---|---|---|
| `name` | `str` | Alias or reference name. |

### `TList`

A list of types. `k` says whether it is a union (`K.tunion`) or a parameter list (`K.tparams`).

| field | type | meaning |
|---|---|---|
| `ts` | `[Type]` | The member types of a union or parameter list. |

### `TPat`

A type pattern used by match arms.

| field | type | meaning |
|---|---|---|
| `names` | `[str]` | Pattern binding names. |

### `TPtr`

A pointer to another type.

| field | type | meaning |
|---|---|---|
| `to` | `Type` | The referenced type; may be recursive. |

### `TInt`

A sized integer (`i8`, `u32`, ...), used behind a pointer or inside a packed record.

| field | type | meaning |
|---|---|---|
| `w` | `long` | Integer width in bytes. |
| `sg` | `bool` | True for a signed sized integer. |
| `be` | `bool` | True for a big-endian sized integer. |

### `TPack`

A packed record or bits record; `bk` is the bit width for a bits record.

| field | type | meaning |
|---|---|---|
| `fields` | `[Field]` | Record or packed fields, in layout order. |
| `bk` | `long` | Bit width for a bits record; 0 for a packed record. |

### `TRef`

A recursive alias reference. `to` may point back into the type graph, so walkers decide whether to descend.

| field | type | meaning |
|---|---|---|
| `name` | `str` | Alias or reference name. |
| `tmp` | `str` | Recursive-alias placeholder used while the type is encoded. |
| `to` | `Type` | The referenced type; may be recursive. |

### `TInfer`

The checker's in-progress return-type marker while a def is inferred.

| field | type | meaning |
|---|---|---|
| `rets` | `[RetNote]` | Return statements the checker has seen while inferring. |

### `TFree`

An unknown element/payload in `[]` or `none` before context fills it in.

| field | type | meaning |
|---|---|---|
| `free` | `bool` | True when the element/payload is still unknown. |

### `TPend`

A def's return type while its body is being checked.

| field | type | meaning |
|---|---|---|
| `self` | `bool` | True while a self-call is being inferred. |
| `used` | `bool` | True once a self-call needed the pending type. |

### `Err`

Error poison; keeps a failed check from cascading.

_No shape-specific fields._
