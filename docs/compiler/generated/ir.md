# Machine IR

> Generated by `src/tools/compiler_docs.y` from `src/y/ir_schema.y`.
> Do not edit this file by hand; run `make compiler-docs`.

The native backend emits a flat `[long]` instruction stream. Every item occupies **eight words** (`IR_W` in `ir.y`): the first word is a form id, the next seven are operand fields. The form's `wire` string says how many words each operand uses; unused words are zero.

Three ids are not forms:

- `IR_LABEL = 200`: one word, a label id.
- `IR_LOC = 201`: two words, file and line for `.loc` under `-g`.
- `IR_TEXT = 202`: one word, an index into the body's raw-text table.

Form ids are the positions in `IR_FORMS`; `ir_forms.y` generates `F_<NAME>` and `O_<NAME>` constants and the `IrForm` table. `ir.y`'s `ir_render_all` turns the packed words back into the mnemonic listing used by `--dump=ir` and `--emit=asm`.

## Operand kinds

| constant | wire | meaning |
|---|---|---|
| `O_REG` | `ww` | A register number plus its width in bits (two words). |
| `O_IND` | `ww` | An indirect register operand: `*%reg`. |
| `O_IMM` | `w` | An immediate word. |
| `O_LBL` | `l` | An interned label id. |
| `O_DIFF` | `ll` | Two interned labels, rendered `$labelA-labelB`. |
| `O_MEM` | `wwwwl` | A memory operand: base, index, scale, displacement and label id (five words). |
| `O_FS` | `w` | A thread-local offset for `%fs:`. |
| `O_MEM0` | `wwwwl` | Like `MEM`, but with an omitted zero displacement in the listing. |

`w` is one numeric word and `l` is one interned label id.

## From packed words to a listing

`mov $1, %rax` is one `F_MOV_I_R` item, form id 36.
Its eight words are:

```text
[36, 1, 0, 64, 0, 0, 0, 0]
 |  |  |   |
 |  |  |   +-- REG width (64 bits)
 |  |  +------ REG number (0 = %rax)
 |  +--------- IMM value
 +------------ form id (F_MOV_I_R)
```

The remaining four words are padding: every item has seven operand
slots, and this form's operands use only three. A label operand
instead stores an interned label id, which is why the listing can
print names while the packed stream stays numeric.
