# Native code-generation dispatch

> Generated by `src/tools/compiler_docs.y` from `src/y/dispatch_schema.y`.
> Do not edit this file by hand; run `make compiler-docs`.

`native_dispatch.y` expands `NATIVE_DISPATCH` into `gen_go`, the `Node -> EmitSt` function at the center of code generation. The table is ordered: the first matching `k` wins, and the final arm calls the special-node handler.

Rows are `KIND[ KIND...]|BINDING: SHAPE|CALL`. The kind column names `tags.y` constants (`K.num`), the binding is the exact record the arm casts to, and the call is the handler the arm invokes.
