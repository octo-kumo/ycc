# os/manifest.txt -- what `ytest os-build` puts into the Y-OS filesystem image.
#
#   dest-path  kind  source  [flags...]
#
# kinds:
#   uland  a program in os/uland: `source` is the file name there (sh.y)
#   y      `ycc source -o ...`; source relative to the repo root (or absolute);
#          flags are extra ycc arguments (e.g. --gc=never)
#   build  `ycc build` run in the directory `source`; a flag out=REL names the
#          product, relative to that directory (required)
#   file   `source` copied in as it is
#   dir    an empty directory (source is -)
#
# `$NAME` in a source is taken from the environment.  The flag `optional` skips
# an entry whose source is missing, with a note, instead of failing the build.
# Order matters: files appear in a directory in the order they are listed here,
# and the session transcripts in test/os/ depend on it.
